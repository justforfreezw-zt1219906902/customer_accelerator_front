# AI Instruction Records

Important Codex or Claude tasks are recorded here. Use
`docs/templates/ai-instruction-template.md`.

## Required fields

- Task ID
- Date
- Tool
- Operator
- Starting baseline
- Files read
- Full prompt or prompt reference
- Permitted scope
- Prohibited scope
- Files created
- Files modified
- Files preserved
- Validation
- Errors
- Human review
- Git commit
