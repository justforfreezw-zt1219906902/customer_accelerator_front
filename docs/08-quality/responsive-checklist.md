# Responsive Checklist

## Source and baseline

- [ ] Figma version, node IDs, Frontend version, and compatibility baseline recorded
- [ ] Exact breakpoints derived from approved Phase 2 tokens
- [ ] Required devices/viewports and browser matrix approved
- [ ] Content/locales and component states included

## Layout

- [ ] No unintended horizontal scrolling
- [ ] Sections and Pages preserve hierarchy at every required width
- [ ] Text reflows without clipping, overlap, or loss
- [ ] Images and product previews scale/crop as approved
- [ ] Grid and column changes match responsive intent
- [ ] Sticky/fixed elements do not obscure content or focus

## Navigation and interaction

- [ ] Header/mobile navigation remains operable
- [ ] Anchors account for header offset and focus
- [ ] Controls preserve target size and spacing
- [ ] Forms remain usable with virtual keyboards and zoom
- [ ] Hover-only behavior has touch/keyboard equivalents

## Initial review widths

- [ ] `1440` desktop
- [ ] `1024` tablet
- [ ] `768` tablet/mobile boundary
- [ ] `390` mobile

These are review targets, not approved CSS breakpoints. Exact breakpoints remain
subject to Phase 2 token extraction.

## Evidence

- [ ] Screenshots and interaction evidence captured
- [ ] Component states and locales identified
- [ ] Issues and Deviations linked
- [ ] Human responsive review recorded
